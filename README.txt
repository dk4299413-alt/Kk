ROYAL TAMIL WEDDING E-INVITATION

Files:
- index.html
- style.css
- script.js
- wedding.mp3 (add your own MP3 here)

IMPORTANT CUSTOMIZATION:
1. Open index.html and replace ARUN / PRIYA, dates, times, venue and family text.
2. In script.js replace 919999999999 with the couple's WhatsApp number.
3. Put your music file in this folder and name it wedding.mp3.
4. The music starts only after "EXPLORE INVITATION" because modern browsers block autoplay.
5. Open index.html in a browser or deploy the folder to GitHub Pages / Netlify / Vercel.

The gallery currently uses premium CSS placeholders so the website works without external image files. Replace the .photo blocks with <img> elements when you have the couple photos.
